# 指标口径与诊断框架

## 漏斗

```
曝光 ──封面点击率──▶ 观看 ──停留──▶ 互动(赞/藏/评/享) ──▶ 涨粉 / 主页访客
```

沿漏斗从上往下找第一个明显漏的环节，那就是这次要改的地方。同时漏两层以上时，只修最上面那层——后面的问题往往是最前面那层的后果。

## 哪些能横向比较

| 指标 | 跨笔记可比 | 说明 |
|---|---|---|
| 曝光 | 否 | 累计值，且新旧笔记的累计速度不同 |
| 观看 | 否 | 同上 |
| 封面点击率 | 是 | 比率；但会受初始推送人群精准度影响 |
| 人均观看时长 | 是 | 需等 72 小时稳定；图文普遍低于视频 |
| 点赞/收藏/评论率 | 是 | 一律除以该篇观看数，不要除以曝光 |
| 涨粉 | 只看比率 | 涨粉/观看，绝对数没有意义 |

账号页的「封面点击率」是加权值（总观看/总曝光），和 `notes` 输出的 `weightedCoverCtrPercent` 应对得上；对不上说明两次读取之间又有新数据进来，属正常。

## 判断规则

没有公开的同赛道基准线，用**这个账号自己最好的那篇**当基线，比套用外部数字可靠。

- **CTR 低于账号历史均值** → 封面或标题在信息流里没说服力，先改这两样，别动内容。
- **图文停留 < 10s** → 基本只翻了封面；> 15s 才算真的在读。
- **收藏 > 点赞** → 工具型内容（配方、清单、步骤），用户想存着以后用，但没到想分享的程度。
- **涨粉/观看 < 1%** → 内容被消费了，但没给出关注理由。
- **主页访客远小于观看** → 没人想看你还有什么，系列感和账号定位没建立。

## 组合症状 → 病因

| 症状组合 | 最可能的原因 | 先验证 |
|---|---|---|
| 低 CTR + 高互动率 | 包装问题，内容本身没问题 | 标题/封面是否被改弱过 |
| 高 CTR + 低停留 | 封面标题过度承诺 | 首图与正文是否对得上 |
| 高停留 + 低互动 | 信息够但没给行动理由 | 结尾有没有明确的下一步 |
| 全指标都低 | 选题或人群不对 | 粉丝画像和内容品类是否匹配 |
| 曝光持续低但 CTR 正常 | 平台没继续推 | 是否 72h 内、是否触发违规词 |

## 报告结构

1. **结论先行**：一句话说是哪一环漏了。
2. **数据表**：曝光、观看、CTR、互动、停留、涨粉，按发布时间排。
3. **证据链**：把草稿标题和实际发布标题并排列出来，或指出粉丝画像与品类的错配。
4. **动作**：2–3 条，按杠杆排序，每条写清"改什么、改成什么、达到什么数字算成功"。
5. **不确定性**：样本量、观察窗口、以及哪些只是推断。

## 不要做

- 不要按曝光给笔记排名——那只反映发布早晚。
- 不要用观看 30 上下的单篇下绝对结论，只用它做方向提示。
- 不要把本地推断说成平台结论（例如把"标题改弱了"说成"平台判定标题质量低"）。
- 不要给"多更新就会好"这类无法验证的建议。
